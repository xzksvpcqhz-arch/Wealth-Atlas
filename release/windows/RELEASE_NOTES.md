# Wealth Atlas v{{VERSION}} Windows 发布说明

本次新增「设置 → 我的显示方案」。每套包含完整桌面、平板、手机布局，现有字号、字重、动画和侧边栏隐藏设置。支持另存、复制、重命名、选择预览、二次确认应用和删除单套方案。选中不等于应用；当前使用的方案须先切换再删除，有未保存草稿时必须先另存或取消切换。
方案库独立于财务资料及现有当前显示配置，使用独立账号表与本人访问权限。同步方案库不会自动切换当前排版；确认应用才更新当前显示配置，沿用原有显示同步规则。并发冲突须明确选择整份方案库，不自动合并或静默覆盖；本机未绑定方案不自动归入登录账号。
方案库不含财务记录，删除方案不删除页面、交易或 Vault。更新不会自动创建示例方案，不会覆盖已有显示设置。

以下此前功能保持不变：

本版本在「我的投资」增加独立的本机账号投资空间：使用现有登录账号，经明确确认后从空白开始。不同账号分别保存，重开后保留记录和保存位置。
仅本机，不跨设备同步，不新增投资云端表；不自动读取或导入原 Vault，不自动写入 Obsidian。原 Vault 工作台保持原流程，切换本页工作区保留未保存表单，离开页面前仍应保存需要保留的输入。
原财务 JSON/云端快照不包含这个独立投资空间。不要通过清缓存、清数据库或恢复原财务 JSON 来处理投资空间问题。
投资保存采用版本及完整状态比较，版本正文与索引原子提交；并发、迟到操作、损坏资料或保存失败时停止写入，不用空白资料替代，也不自动修复或恢复。
保留备份恢复差异预览及恢复后的本机同步/Vault 暂停保护；保留当前 Obsidian 连接、同步日志、更新中心、首页 DIY 编辑器及账号内显示方案同步。
保留账号隔离、本机历史邮箱选择、自动登录、财务同步及离线重开逻辑。主子关系、账户余额计算、历史交易和历史汇率快照保持不变；不重新设计页面。
发布前须核对源码 commit、版本 tag、构建配置和三项自动更新资产；未确认候选包不得上传为正式版本。

- GitHub 自动更新仅使用公开稳定版本，不要求使用者提供发布 Token，不自动降级。
- 后台下载完成后不会立即关闭应用；正常退出后安装，重新打开使用新版本。
- 网络失败不会阻止启动，返回应用时按间隔重试。
- 发布前校验安装包、清单和 blockmap，全部上传文件通过服务器 SHA-256 核对后才公开。
- 保留同步版本竞争、冲突暂停、删除恢复传播及待同步队列保护，不以空白资料覆盖读不到的原工作区。
- 各账号使用对应本机工作区；原本未绑定账号的本机资料保持独立，不自动上传或采用测试包资料。
- 本机历史账号只在用户勾选并成功登录后记住邮箱；选择历史项仅回填邮箱，不保存密码、不自动登录。
- 保留“下次自动登录”开关，复用现有有效会话，不保存密码或额外令牌副本；关闭只影响下次打开，不退出当前账号。
- 自动登录关闭后，后台联网/焦点事件不能打开账号资料；密码重设链接被消费后刷新仍能恢复表单，恢复流程不自动打开财务工作区。
- 保留密码重设表单的恢复状态、失败重试和重复提交保护。
- 已验证本机工作区可按现有验证期限离线读取；联网后重新验证成功再恢复同步，不保证无限期离线登录或所有设备的历史故障均已消失。
- 最终运行验收绑定安装包、blockmap 和更新清单的 SHA-256；重新构建或签名后必须重新验收。
