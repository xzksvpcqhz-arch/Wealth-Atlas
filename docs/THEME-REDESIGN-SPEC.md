## 1. 总体架构：可切换外观引擎

在现有单页应用上叠加一层 **外观引擎**，由 4 个独立轴组成，用户可在设置页自由组合：

| 轴 | 取值 | 说明 |
|---|---|---|
| **模式** night/day | 深色 5 主题 / 浅色 3 主题 | 顶部快捷按钮在"上次用的夜主题"与"上次用的日主题"间切换 |
| **主题预设** | 8 个（见 §2） | 决定画布/表面/文字/边框色系 |
| **强调色** | 8 个预设（见 §3） | 青/蓝/紫/粉/橙/绿/金/红，独立于主题 |
| **面板样式** | 标准 / 玻璃 | 独立开关：玻璃 = 低透明度填充 + `backdrop-filter: blur()` + 圆角 |

**实现机制**：全部视觉 token 收敛为 CSS 变量，根元素挂 `data-mode` / `data-theme` / `data-accent` / `data-panels` 四个属性；切换即时生效（改属性即换肤），选择持久化到 localStorage（沿用 v1.1.0 导航持久化的"非敏感 UI 偏好"模式）。

**入口**：
- 顶部导航栏：日/夜快捷切换图标按钮（月亮/太阳，带 tooltip）
- 设置页新增「外观」区：主题 8 卡选择、强调色 8 圆点、玻璃开关

## 4. 字体

- **标题 + 所有数字金额**：Space Grotesk（`font-variant-numeric: tabular-nums`）
- **正文**：现有系统字体栈（PingFang/Microsoft YaHei 等，中文渲染更稳）
- 无衬线单轴：不引入第二个展示字体

## 5. 玻璃面板（独立开关）

| 表面 | 标准 | 玻璃（开） |
|---|---|---|
| 左侧导航栏 | 现有填充 | 低透明度填充（主题相关 7–20%）+ `blur(16–20px)` + 圆角 |
| 弹窗/确认框 | 现有 | 低透明度 + 模糊 + 更大圆角（16–20px）|
| 数据面板/卡片 | 现有半透明 | 模糊（12–16px），填充透明度略降 |
| 顶部快捷工具栏 | 现有 | 模糊 + 圆角 |

浅色主题下玻璃模糊同样生效（白玻璃），透明度适配亮底。

## 6. 信息架构（先做 3 个核心页，密度选项见待确认项）

**首页**：快捷工具栏（玻璃）→ 自由资金 hero → 今日速览（收入/支出/结余/汇率）→ 目标星图 → 30 天现金流 → 提醒/洞察
**账户管理**：分组（按根账户）→ 主账号卡 + 子账户紧凑行 → 停用/回收区
**收支记录**：月份选择 + 收支过滤 tabs → 记录行（金额右对齐等宽数字）→ 删除/恢复流程不变

## 7. 数据模型（第二阶段，纯增量）

- 信息架构确认后，再做数据模型微调；**只允许 additive 迁移**（schema 11 预留），绝不删字段/改历史数据
- 候选：外观偏好存 settings（新字段，additive）；账户/分类结构如需调整走新迁移 + 迁移备份（沿用现有机制）

## 8. 硬约束（全部保持）

- 390px 移动端无横向溢出；`prefers-reduced-motion` 生效
- 软删除/回收站/永久删除二次确认、迁移备份、Obsidian 受保护区、Excel/PDF/PNG 导出
- 深色/浅色都满足 WCAG AA 对比度；数字可换行不裁剪
