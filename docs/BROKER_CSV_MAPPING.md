# 券商投资 CSV 栏位映射模板

入口：我的投资 → 对账与导入。本功能不修改日常收支 CSV 导入。

## 使用

1. 选择完整账户快照或成交与资金流水，填写原有券商、匿名账户标签、来源及币种资料。
2. 明确选择自己的 CSV，或粘贴 CSV 内容。程序不会自行扫描账单目录或 Obsidian。
3. 为每个必需投资栏位选择 CSV 来源栏位。不会自动猜测别名、日期、交易类型、正负号或汇率；快照中的证券名称可不对应，沿用证券 ID。
4. 可将对应关系另存为命名模板。下次选择模板后，仍须点击“应用所选模板”。有未保存的映射时，替换需再次确认。
5. 点击原有“检查导入资料”，核对原币、报告币、现金、日期与来源，再点击“确认保存”。模板保存不是投资记录保存。

模板名称为 1–30 个 Unicode 字符，先作 NFKC 与首尾空白规范化；不接受控制字符，最多 10 套。名称在快照和流水之间共用，ASCII 大小写不能用于建立重名模板。

## 保存边界

- 模板仅包含 ID、名称、资料类型、表头和栏位对应关系。
- 不保存 CSV 行、账户标签、账单来源、现金、金额或汇率数值。
- 新的本机数据库为 `wealth-atlas-investment-csv-mappings-v1`；按当前本机／访客／云账号工作区隔离，不改变财务数据库或已有投资记录的格式。
- 模板不跨设备同步，不写入 Vault，不进入财务 snapshot。投资跨设备同步是独立功能，需单独授权和验收。
- 读取不会建立模板记录；数据损坏或读取失败不会用空白模板库覆盖原记录。
- 保存采用原模板库版本与完整内容的原子比较。其他窗口已修改时暂停，不自动合并或覆盖。
- 删除模板需确认，仅删除模板，不会删除当前 CSV、检查结果或投资资料。

## 导入保护

支持 UTF-8（包括开头 BOM）、逗号分隔、标准引号转义、CRLF／LF／CR 行尾及引号内换行。文件和映射后内容均限 2 MB，最多 20,000 笔、128 栏。重复／缺失表头、错列、不完整映射、重复来源映射、非明确数字或日期会阻止继续。

模板只对应确切表头，不按数组序号猜测。表头顺序变化可以复用；映射引用的名称改变则需人工重新核对。没有对真实 IBKR、moomoo 或其他券商的全部导出格式作兼容性保证。

映射后的 CSV 仍交由既有 `ledger-model.cjs` 校验和去重／冲突逻辑处理。更改 CSV、栏位或账户表单会使旧检查结果失效；迟到的文件读取不能覆盖已切换页面的输入。

## 开发验收

相关测试：

- `node --test tests/investment-csv-mapping.test.mjs`
- `node --test tests/investment-csv-store.test.mjs`
- `node --test tests/investment-csv-ui.test.mjs`
- `npm test`
- `npm run build`

界面及数据库测试只使用独立的虚构 profile，阻断外网请求，不读取个人账单、真实 Vault、凭证或真实财务资料。模拟／隔离验收不能代替真实券商兼容性、实际安装向导或两台真实设备同步验收。
