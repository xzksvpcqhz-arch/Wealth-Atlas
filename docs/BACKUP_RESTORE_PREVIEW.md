# 备份恢复预览与本机隔离

候选版本：v1.7.10。只扩展设置页的备份与恢复，不自动恢复任何用户资料。

## 操作顺序

1. 选择「预览恢复」。只读取所选备份，比较当前工作区与一次性准备的恢复候选。
2. 查看新增、改变、相同、当前独有记录；按类型及真实 ID 比较。无 ID 的历史按完整内容及重复次数比较。停用、回收站、未知字段也在比较范围。
3. 当前独有资料不会出现在整份替换后的工作区；不是自动合并。当前 Obsidian 连接和同步日志保留，不用旧备份回滚这些操作状态。
4. 继续后出现单独确认及勾选框。取消、Escape、点击外部不恢复；执行期间不能重复确认或关闭弹窗。
5. 校验账号、当前资料与所选备份仍未变化。等待在途同步及 Vault 自动快照完成，单独保存并读回校验当前资料的安全备份，不复用启动备份、不参与滚动清理。
6. 在同一 IndexedDB 事务内检查当前内容与恢复代数，再提交候选快照与暂停标记。失败不发布内存状态或成功提示。
7. 只有持久化成功后刷新页面资料。该本机工作区的云端上传、接收与 Vault 自动快照写入持续暂停，重开后仍暂停。
8. 用户另行核对并明确确认「恢复自动写入」后才解除。保留原同步基准、删除标记、待同步队列与账号会话；不是强制云端回退，可能合并或因冲突停止。

## 保护边界

- 不改变财务快照字段、schemaVersion 或数据库 store/version；暂停标记是原 snapshots store 中独立的本机工作区元资料。
- 普通编辑继续保存本机。恢复代数在事务内拒绝旧窗口、旧队列把恢复后的资料覆盖回去；旧窗口须重新载入后编辑。
- 自动 Vault 快照与完整云同步使用同一工作区的跨窗口 Web Locks。缺少可靠隔离支持时拒绝恢复，不降级为不安全写入。
- 不暂停其他设备，不暂停独立账号显示方案同步，不改变用户主动执行的 Obsidian 预览／确认写入流程。
- 旧版本不认识新暂停标记。**恢复保护暂停期间不要降级到 v1.7.9 或更早版本，也不要同时用旧程序打开同一工作区。** 暂停并非云端或系统层面的访问权限撤销。
- 早期无校验码备份会明确提示「没有原始校验码」，仅支持来源可信的本机旧备份。缺少校验码与已提供但不匹配是不同状态；后者必须停止。
- 预览中的字段内容只显示在当前设备，不输出到日志、遥测、Git 或审核文件。测试只用虚构资料和独立 profile；不读取真实备份或 Vault。
- 不改变既有自动快照保留规则，也不宣称所有账号工作区最多保留 10 份。新建恢复安全备份不清理旧文件；损坏、部分写入或失败产物也不自动删除。

## 验证

`npm test` 包括纯比较／验证、备份文件安全与真实隔离 IndexedDB/Web Locks 测试。

`node scripts/backup-restore-desktop-test.cjs --stage=<独立静态源码副本>` 验证实际设置页、主进程和 sandbox preload；外部网络阻断，只用虚构资料。界面证据包括 1440×900、1280×800、390×844、320×720。

安装包 payload 验收不等同真实 NSIS 向导、注册表、快捷方式或所有实体设备测试。无正式签名证书时仍标记 UNSIGNED，不声称 Windows 自动信任。
